Este é um artigo de demonstração. Para publicar um texto seu, crie outro arquivo `.md` nesta pasta e substitua o conteúdo de exemplo.

## Uma ideia por vez

Escreva os parágrafos como em qualquer arquivo Markdown. O texto pode ser dividido em seções para ajudar o leitor a acompanhar o raciocínio.

Você pode enfatizar uma ideia com **negrito**, usar *itálico* para uma nuance ou incluir um [link para outra página](https://pt.wikipedia.org/wiki/Markdown).

> Uma citação pode dar destaque a uma frase ou a uma passagem que mereça atenção.

### Uma pequena lista

- Cada item começa com um hífen.
- As tags ficam no início do arquivo, no campo `tags`.
- Cada tag vira um link para os textos daquele assunto.

Ao salvar o arquivo, o Astro cria a página do artigo e o inclui automaticamente na lista, no RSS e nas páginas de assuntos.
